01 / 为什么做

很多事不是你不会，
是没人一次讲清楚。

刚出社会，最先缺的不是努力，是一份能照着办的顺序。

入口散在四个官网

社保、医保、公积金、就业，各去各的网站，各有一套说法。知道要找谁，往往比知道政策本身更难。

答案都很确定，依据很少

短视频、帖子和中介，说得都很像真的。很少有人告诉你这条依据哪份文件、哪一年、还生不生效。

先办哪件，比算多少钱更急

欠薪、医保断缴、试用期被辞退，先做什么会直接影响后面能拿什么。算钱之前，得先知道下一步。

先把事办成，再谈钱。
算钱是清单里的工具，不是整个产品。

04 / 数据边界

它不假装
什么都知道。

政策会变，城市会变，经办口径也会变。与其给一个看起来很确定的错答案，不如把来源和不确定都摆在明面上。

official

能追到文件

每条官方数值都对应政府文件或公开来源，来源链接可点开对照。不是“网上都这么说”。

derived

推算出来的，标出来

由官方数字计算得出、不是直接公布的值，明确标为推算，并把算法和假设写清。

unverified

没核到，就空着

没有权威来源的字段只作为假设展示，不当事实。平台按单计价永远是待核验，因为它是商业价格，不是公开政策。

几个
常被问的问题。

如果这里没回答，去仓库开 issue，或者直接看 README 和更新日志。

这些金额准吗？+

它是测算，不是承诺。每个结果都能展开看到假设、公式和来源；政策数值会标注官方、推算或待核验。具体能拿多少，以当地经办机构的口径为准。

为什么不做一键代办？+

不代办，不代缴，不卖课，也不推荐贷款或保险。这个产品只做一件事：把该做什么、能拿什么、去哪办讲清楚，让你自己走到官方入口。

会上传我的信息吗？+

没有后端、没有账号、没有遥测，也没有第三方 JavaScript。聊天记录和 API Key 默认只留在浏览器；只有你主动勾选“记住”才会保存，AI 只把问题和计算上下文发给你自己配置的接口。

为什么安装包会提示“未知发布者”？+

0.1.2 的安装包没有做代码签名证书。SmartScreen 对未签名的新程序会保守提示。下载后先核对页面里的 SHA-256，确认文件完整再运行；也可以从源码自行构建。
